A company Oden tracks the cities where it operates on each business day.

You are given a table business_city that stores:

the date of operation

the city ID where operations occurred

A city may appear multiple times across years.

🎯 Task

Write an SQL query to find the year-wise count of NEW cities where Oden started operations for the first time.

🔍 Important Clarification

A city is considered new in a year if it never appeared in any previous year

Repeating the same city in later years must not be counted

You must compare current year vs all previous years

🗂 Table Structure

CREATE TABLE business_city (
    business_date DATE,
    city_id INTEGER
);
